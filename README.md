This repository contains all files used in the preparation of the term paper for the seminar “Veto Players in Comparative Perspective” (Master Political Science). The repo contains functions to calculate the yolk of a parliament (src/yolk_functions.py), the code that combines [MARPOR](https://manifestoproject.wzb.eu/datasets) and [PAGED](https://repdem.org/index.php/current-dataset/) data into a combined data set (build_parliament_bib.py), and the subsequent analysis of the data (analysis.ipynb).
